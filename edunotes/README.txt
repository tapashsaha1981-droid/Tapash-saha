EduNotes Pro — Phone Login Restored

Student login:
- Select Student Login.
- Enter the student's registered 10-digit mobile number.
- No password is requested.
- The app normalizes the number to +91 and signs in to the existing Supabase student account using the app's established synthetic student email and phone-number password.
- The existing student profile/device checks remain in place.

Admin login:
- Select Admin Login.
- Enter admin email and password.

Files:
- index.html — EduNotes Pro app with restored phone-only student login.
- sw.js — service worker from the supplied push-fix package.
- pushNotifications.js — supplied push notification module.
- icon-192.svg — supplied app icon.

Important:
This package is for the separate EduNotes Pro student-facing deployment. Do not replace the Tuition Manager Render frontend with it.
